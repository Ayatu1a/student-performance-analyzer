# Student Performance Analysis System

## 1. Project Description

The Student Performance Analysis System is a Python application designed to analyse university student academic performance.

The system reads student records from a CSV file, calculates academic averages, assigns grades, identifies scholarship-eligible students and generates individual performance reports.

## 2. Technologies Used

- Python 3
- CSV
- Visual Studio Code
- Object-Oriented Programming (OOP)

## 3. Project Features

- Loads student records from a CSV dataset.
- Calculates individual student averages.
- Assigns academic grades.
- Identifies scholarship-eligible students.
- Calculates the highest student average.
- Calculates the lowest student average.
- Calculates the overall class average.
- Generates individual student performance reports.

## 4. OOP Concepts Demonstrated

- Classes and Objects
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism
- Method Overriding
- Flexible Method Interfaces

## 6. Scholarship Eligibility

Students with an average score of 85 or above qualify for a scholarship.

The illustrative scholarship amount used is KES 50,000.

## 7. How to Run the Project

1. Install Python 3.
2. Download the project repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Execute the following command:

```bash
python3 main.py
```

6. The system will load the student dataset and generate performance reports.

## 8. Dataset

The students.csv file contains student IDs, names, programmes and marks in Mathematics, English and Science.
